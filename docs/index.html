Engineered Subsystems

Every stage from microphone sample acquisition to verified tool execution runs locally inside an auditable Rust workspace.

Calibrated Decision & Clarification

BM25 candidate retrieval paired with FNV-1a semantic hashing, multi-feature scoring, softmax + Platt joint probabilities, and persistent session-scoped clarification across ordinals, rephrasing, missing arguments, confirmations, and cancellations.

pico-decision / pico-inference

Real Audio DSP & Voice Pipeline

Lock-free cache-aligned SPSC ring buffers, explicit RIFF WAV container decoding, Lanczos-3 sinc resampling to negotiated device rates, sample-counted VAD with 160ms pre-roll, Piper / WinRT OneCore / SAPI5 / eSpeak TTS, and ONNX/Whisper ASR.

pico-audio / pico-voice

Zero-Trust Security Boundary

Fail-closed PathSandbox with symlink/junction checks, DNS-pinned SSRF protection blocking IPv4 & IPv6 tunnels (NAT64/6to4/Teredo), SHA-256 argument-bound single-use confirmations, and Owner-DACL / SO_PEERCRED IPC sockets.

pico-security / pico-core

Lightweight Companion Without GPU Driver Bloat

Moving OpenGL (`eframe/glow`) and heavy ASR/SQLite state out of the desktop UI eliminated 115+ MB of GPU ICD driver overhead.

Media, Volume & Host Telemetry

Reads active playback directly via Windows WinRT GSMTC and Linux MPRIS (`playerctl`), renders WCAG-verified contrast-safe dynamic album artwork gradients, adjusts master endpoint volume over WASAPI / PipeWire, and tracks memory and battery state.

Focus, Notes, Drag-and-Drop Stash & Ask

Includes persistent UTC-backed multi-timers, Pomodoro focus cycles with tray notifications, searchable pin/edit notes, safe non-destructive drag-and-drop file/URL stash, offline inline calculator previews, and authenticated IPC prompts.
