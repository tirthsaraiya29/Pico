ENGINEERING FOUNDATIONS

Architected for Extreme Responsiveness

Engineered without bloated runtimes or third-party cloud intermediaries.

⚡

Native WASAPI Audio & Barge-in

Custom lock-free ring buffer running on dedicated high-priority audio threads with energy-based voice activity detection. Speaks and listens concurrently with sub-15ms barge-in interruption.

🛡️

Zero-Trust OS Sandbox

Strict path boundary verification defending against Windows junctions, symlinks, Alternate Data Streams (ADS), device names (CON/NUL), UNC leaks, and command chaining.

🧠

Interchangeable Local Inference

Native async provider abstraction supporting local Ollama (Granite 4.2 / Llama 3.2), Vulkan-accelerated `llama-server.exe`, and streaming OpenAI-compatible JSON endpoints.

🔢

Zero-Shell Math AST Parser

Dedicated recursive-descent arithmetic parser evaluating expressions, powers, and trigonometry in microseconds with strict recursion depth and float boundaries—completely eliminating PowerShell execution.

💾

Persistent Context Budgeting

SQLite with Write-Ahead Logging (WAL) and token context budgeting. Preserves long-term memory facts, session history, and execution metrics while preventing LLM context overflows.

🌐

Anti-SSRF Web Fetching

Robust DNS resolution and IP range verification blocking loopback (127.0.0.0/8), RFC 1918 private networks, link-local metadata (169.254.169.254), and redirect-based SSRF vectors.

GET STARTED IN SECONDS

Terminal & Voice Interaction

Interact with Pico directly from your shell or launch the visual 3D interface.

pico-cli — PowerShell / Bash
# 1. Run diagnostic system doctor
> pico-cli.exe doctor
[OK] Host OS: Windows 11 x86_64 (Intel Core Ultra 7 356H)
[OK] Audio: Microphones (1), Speakers (1) verified
[OK] Inference: Local Ollama reachable at http://127.0.0.1:11434

# 2. Start interactive assistant with OS tool execution
> pico-cli.exe chat
Pico > "What is (25 * 4) + sqrt(144)?"
⚙ [TOOL] Calling tool: calculator with {"expression":"(25 * 4) + sqrt(144)"}
[OK] Tool calculator completed in 0.05ms: {"result":"112"}
Pico > (25 * 4) + sqrt(144) equals 112.

# 3. Launch Hands-Free Voice Mode
> pico-cli.exe voice
[LISTENING] Speak naturally into microphone. Speak anytime to barge in.
